# 🎉 PartyPlanner Bot

Терминальный чат-бот для планирования и организации вечеринок, разработанный на языке Python. Приложение позволяет создавать мероприятия, управлять списком гостей, проводить голосования за даты и вести финансовый учёт — всё через удобный интерфейс командной строки (CLI).

## 🚀 Возможности

- ✅ Создание вечеринки с уникальным именем
- ✅ Добавление и просмотр списка гостей
- ✅ Голосование за даты проведения
- ✅ Назначение денежных сборов (долгов) участникам
- ✅ Просмотр общего бюджета мероприятия
- ✅ Защита от дублирования данных
- ✅ Полностью офлайн-режим (не требует интернета)
- ✅ Локальное хранение данных в формате JSON

## 🏗️ Архитектура приложения

Приложение построено по принципу **модульной архитектуры** с чётким разделением ответственности:


### Принципы проектирования:

1. **Single Responsibility** — каждая функция отвечает ровно за одну задачу (создание, загрузка, вывод).
2. **Разделение данных и логики** — данные всегда передаются явно, не зависят от глобального состояния.
3. **Fail Fast** — ошибки валидации происходят на самых ранних этапах обработки команды.
